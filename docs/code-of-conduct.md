# 行動規範 (Code of Conduct)

`ido-bata` コミュニティは、Discord サーバと本 Web サイト (https://ido-bata.github.io/) および関連リポジトリから成る、**実利重視・情報共有主体・自由参加脱退** の場です。

この行動規範は、サーバ参加者・Web サイト訪問者・Issue / PR での発言者・運営のすべての当事者に適用されます。

## 1. 基本姿勢

- **実利重視**: 議論は「誰の何の課題をどう解決するか」を軸に進める。感想や世間話だけのチャンネルは用意しない。
- **情報共有主体**: 各自の発言・成果物・失敗談は、コミュニティの資産として公開・共有する前提で扱う。クローズドな有益情報はできる限りオープン化する。
- **自由参加脱退**: 参加も脱退も自由。いかなる理由での休止・退出も非難しない。連絡義務もない。

## 2. 推奨される行動

- 相手の人格ではなく、対象の発言・成果物・挙動にフィードバックを向ける
- 文脈・前提・再現手順をできるかぎり明文化し、Issue / PR / ドキュメントに蓄積する
- 自分が未熟な領域はそれを明示し、レビュー・補完を求める
- 得た知見はブログ・記事・ADR・Issue コメントなど、後から検索できる形で残す
- 多言語・多文化・異なる経験値の人を前提に、用語はできるかぎり定義する

## 3. 望ましくない行動

以下は歓迎しない。悪意の有無に関わらず、起こった時点で対象者に通知し、改善が見られない場合は参加の制限を検討する。

- 個人攻撃・差別・ハラスメント・脅迫・性的な嫌がらせ
- 業務上・私生活上の機密情報、PII、認証情報 (token / API key / パスワード等) の投稿
- スパム・荒らし・宣伝・Scam リンクの配布
- 他者の発言・成果物の無許諾転載 (出典と許諾を明示すれば可)
- 特定の政治的・宗教的立場への組織的な布教・扇動
- 運営の判断に対する、公開チャネルでの人格を否定する形での抗議 (建設的な異議申し立ては歓迎)

## 4. Discord サーバ固有の取り決め

- サーバ内のロール・チャンネル運用は運営の裁量による。割り当てに異議がある場合は DM ではなく公式の問い合わせ窓口経由で伝える
- 荒らし・スパム・DM スパムを受けたら、チャンネルに晒さず運営に通報する
- Bot 連携や外部 Webhook の導入は、サーバの規約および各サービス利用規約に従う
- リージョン固有の法令 (GDPR / APPI 等) に抵触し得る情報を、サーバに貼り付ける前に必ず取捨選択する

## 5. Web サイト・GitHub リポジトリでの取り決め

- Issue / PR / Discussions は public に公開される前提で、機密情報を含めない
- 自分の投稿が第三者の権利 (肖像・著作物・商標) を侵害していないかを確認する
- コード・記事・画像等の投稿は、ido-bata 組織のライセンス方針 ([`LICENSE`](./../../LICENSE) 等) に従う
- セキュリティ上の問題は公開 Issue には書かず、[`docs/security.md`](./security.md) の窓口を利用する

## 6. 違反の報告

違反を見つけた場合、または違反の対象になった場合は、以下のいずれかで報告する。

- **GitHub Security Advisories** (推奨): https://github.com/ido-bata/ido-bata.github.io/security/advisories/new
- **運営者 (さむいど) への direct contact**: GitHub アカウント `@samuido` (https://github.com/samuido) へ DM または email
- 緊急を要しない一般的な相談は [`CONTRIBUTING.md`](./../CONTRIBUTING.md) の手順に従い Issue を作成してよい

報告時に含める情報:

- 発生日時と場所 (サーバ channel、Issue / PR 番号、commit SHA 等)
- 対象のユーザ / 投稿 (可能なら URL・スクリーンショット)
- 影響範囲と、できれば再現手順
- 既に講じた対処 (あれば)

報告を受けた運営は、内容を確認の上、削除 / 警告 / 一時停止 / 永久追放 / 公開停止など、適切な対応を判断する。通報者の匿名性は、合理的な範囲で保護する。

## 7. 改定

- 本規範はコミュニティの運用状況に応じて不定期に見直す
- 改定は運営が発議し、本リポジトリの `docs/code-of-conduct.md` を更新する Pull Request で行う
- 大きな変更は、Discord サーバおよび本ページ上部に告知する
- 改定後も、本規範の改訂日を確認し、不同意であれば参加を停止する (自由参加脱退)

## 8. 謝辞

本規範は、Contributor Covenant および GitHub の Community Guidelines の考え方を参考に、`ido-bata` の方針に合わせて簡略化したものです。テンプレートの流用提案は歓迎します。
